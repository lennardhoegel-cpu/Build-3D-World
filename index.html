Globale Community-Datenbank (Für alle Besucher)

Globale Cloud ist AKTIV! Alle veröffentlichten 3D-Modelle, Likes, Saves und Follower werden dauerhaft gespeichert und sind für alle Besucher weltweit sichtbar.

Warum braucht GitHub Pages eine Datenbank? GitHub Pages ist ein reiner Datei-Hoster ohne eigenen Speicher. Ohne zentrale Datenbank bleiben Modelle nur im eigenen Browser.

So machst du deine GitHub-Pages-Seite in 1 Minute dauerhaft für alle Besucher weltweit live:

  1. Erstelle ein kostenloses Projekt auf console.firebase.google.com.
  2. Aktiviere dort Firestore Database (im Testmodus) und Authentication → Anonym.
  3. Kopiere deine firebaseConfig (das { apiKey: "...", ... } Objekt) unten hinein oder fest oben in die HTML-Datei bei CUSTOM_FIREBASE_CONFIG.
